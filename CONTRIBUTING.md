# Contributing

Thanks for helping improve this competency handbook. Fixes and additions are welcome.

This repository is a competency handbook for checking and growing real-work skills across AWS, Azure, and Google Cloud.

## Before you start

* Open an issue first for big changes, such as new sections, restructuring, or a new provider.
* Keep each pull request to one topic.

## Style

* Keep the existing structure: a question-style heading, a short answer, then lists or tables instead of long prose.
* Keep the voice concise and practical.

## Accuracy

* Verify facts against official AWS, Azure, and Google Cloud documentation.
* Use current service names, for example Microsoft Entra ID (not Azure AD).

## Markdown

* Keep heading levels sequential.
* Make sure every link and table-of-contents anchor works. The link check CI must pass.

## Commits

Use [Conventional Commits](https://www.conventionalcommits.org/) with a one-line subject, for example:

* `docs: add failover routing question for AWS`
* `fix: correct Microsoft Entra ID role name`
* `chore: update link check workflow`
